# Modbus RTU 实时分析上位机

这个工具用于在 Windows 上实时读取串口数据，按 Modbus RTU 帧解析，并把关键寄存器和值显示出来。

## 运行

```bat
cd /d D:\RT-ThreadStudio\workspace\canopen_stm32-v1.1-uart-split\tools\modbus_host
python -m pip install -r requirements.txt
python modbus_host.py
```

也可以双击 `run_modbus_host.bat` 启动。

## 默认参数

- 波特率：`115200`
- 数据位：`8`
- 校验位：`None`
- 停止位：`1`
- 分帧间隔：`20ms`
- 在线检测站号：`1`
- 自动采集间隔：`2s`

如果一帧被拆成多行，把“分帧间隔ms”调大；如果多帧粘在一起，把它调小。

## 功能

- 自动刷新和选择 COM 口，下拉框会显示端口号和系统设备名称。
- 实时读取 RX 数据并显示原始 HEX。
- 解析 Modbus RTU 功能码 `0x03`、`0x04`、`0x06`、`0x10`。
- 校验 CRC。
- 对常用寄存器显示中文名称和关键动作含义。
- 支持手动发送 HEX，可自动追加 CRC。
- 支持“在线检测”，发送只读检测帧 `01 03 00 11 00 02 + CRC`。
- 支持“自动采集”，按设定间隔重复发送只读检测帧并自动解析响应。
- 支持保存抓包结果为 CSV。

## 在线检测

连接串口后，设置站号，点击“在线检测”。工具会发送只读帧：

```text
站号 03 00 11 00 02 CRC_L CRC_H
```

收到合法响应、CRC 正确、站号和功能码匹配时，检测状态会显示在线。
超过 `1.2s` 没有收到匹配响应时，检测状态会显示超时。

## 自动采集

设置“采集间隔s”后点击“自动采集”，工具会按间隔自动发送同一条只读检测帧。
收到的数据会进入表格，并立即按 Modbus RTU 格式解析。
再次点击“停止采集”可以停止。

## 注意

Windows 串口通常只能被一个程序打开。如果成品上位机已经占用同一个 COM 口，本工具无法同时读取，需要关闭成品上位机，或使用虚拟串口/串口分线做镜像抓包。
