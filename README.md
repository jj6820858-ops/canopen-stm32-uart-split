# 智能快检设备 RT-Thread 控制工程

本仓库是一个基于 STM32F103 与 RT-Thread 的嵌入式控制工程，用于农残快检设备的主控端软件开发。工程重点放在设备任务调度、执行机构控制、传感采集、状态管理和异常保护等主控功能。

## 工程特点

- 使用 RT-Thread 组织多任务运行流程。
- 将检测流程、运动控制、液路控制、温控采集、状态保护等功能拆分为独立模块。
- 通过设备驱动层统一管理 UART、CAN、GPIO、ADC、PWM、定时器等外设。
- 支持主控初始化、自检、任务调度、运行状态反馈和异常处理。
- 当前版本已对部分地址和对象标识做了重新映射，源码以当前提交为准。

## 目录结构

```text
applications/
  canopen/      主控侧总线与对象字典封装
  core/         应用入口
  gateway/      业务动作转发与采样流程
  protocol/     本地寄存器表与路由
  threads/      线程初始化与外设启动
  workflow/     上电检查与流程控制

canfestival/    CANfestival 移植与对象字典
drivers/        STM32 外设驱动
packages/       RT-Thread 软件包
tests/          调试与验证命令
tools/          本地辅助工具
```

## 构建环境

- RT-Thread Studio 或兼容的 RT-Thread/SCons 构建环境
- STM32F103RCT6 目标板
- ARM GCC 或 RT-Thread Studio 默认工具链

常用构建入口：

```bash
scons
```

也可以直接使用 RT-Thread Studio 打开工程后编译、下载和调试。
