## 硬件接线

```
┌─────────────────────────────────────────────────────────────┐
│  调试电脑 (UART1)                 STM32                     │
│  ┌──────────┐                  ┌───────────┐                │
│  │串口助手   │  PA9(TX) ←──── │ UART1 RX  │  控制台/日志    │
│  │115200 8N1 │  PA10(RX) ────→│ UART1 TX  │  rt_kprintf     │
│  │HEX格式    │  GND ──────────│ GND       │  FINSH shell    │
│  └──────────┘                  └───────────┘                │
│                                                              │
│  上位机 (UART2)                                              │
│  ┌──────────┐                  ┌───────────┐                │
│  │协议主程序  │  PA2(TX) ←──── │ UART2 RX  │  AA55 帧协议   │
│  │AA55帧     │  PA3(RX) ────→│ UART2 TX  │  纯二进制无文本 │
│  │HEX发送    │  GND ──────────│ GND       │                │
│  └──────────┘                  └───────────┘                │
└─────────────────────────────────────────────────────────────┘
```

**连线说明**：调试电脑连 UART1（PA9/PA10）看日志和敲 finsh 命令；上位机连 UART2（PA2/PA3）发 AA55 协议帧。

## 串口参数

| 项目 | 调试口 (UART1) | 协议口 (UART2) |
|------|---------------|---------------|
| 引脚 | PA9(TX) PA10(RX) | PA2(TX) PA3(RX) |
| 波特率 | 115200 | 115200 |
| 数据位 | 8 | 8 |
| 停止位 | 1 | 1 |
| 校验 | 无 | 无 |
| 发送格式 | ASCII / HEX | **HEX 模式** |
| 行尾 | 可加回车 | **不追加任何行尾** |

> ⚠️ **关键**：协议口必须使用 **HEX 模式发送**，且**不能追加回车换行**，否则 XOR 校验失败。

## 帧协议

### 请求帧

```
帧头 2B  | 命令 1B | 地址 2B(LE) | 长度 1B | 数据 NB | 校验 1B
AA   55  |   CMD   | AddrL AddrH |   N     | D0..DN  |  XOR
```

### 成功响应帧

```
AA 55 | CMD | AddrL AddrH | 数据字节数 | 数据... | XOR
```

### 错误响应帧

```
AA 55 | FF | 错误码 | AddrL | AddrH | 00 | XOR
```

### 命令字

| CMD | 含义 | 说明 |
|-----|------|------|
| `0x03` | 读寄存器 | 批量读，长度=寄存器个数 |
| `0x06` | 写单个 | 固定 2 字节数据 |
| `0x10` | 写多个 | 连续写多个寄存器 |
| `0xFF` | 错误（仅响应） | 响应中 FF 表示错误 |

### 错误码

| 错误码 | 含义 |
|--------|------|
| `0x01` | 校验和错误 |
| `0x02` | 未知命令 |
| `0x03` | 地址无路由（或 SDO 超时） |
| `0x04` | 访问权限错误（写只读或读只写） |

## XOR 校验

### 计算方法

XOR 校验字节 = 帧头 + 命令 + 地址 + 长度 + 数据 **所有字节的异或值**。

即：`XOR = AA ^ 55 ^ CMD ^ AddrL ^ AddrH ^ Len ^ D[0] ^ ... ^ D[N]`

响应帧中的 XOR 也按同样规则计算（不含 XOR 本身）。

### 快速校验表

发帧时，可用此表快速查找各字段的 XOR 影响值：

| 字节值 | 影响 |
|--------|------|
| `0xAA` | 固定，始终参与 |
| `0x55` | 固定，始终参与 |
| CMD | 读 `0x03` / 写单个 `0x06` / 写多个 `0x10` |
| AddrL | 协议地址低字节（小端） |
| AddrH | 协议地址高字节 |
| Len | 读=寄存器个数，写=数据字节数 |
| Data... | 每个数据字节都参与 |

### 常用 XOR 速查（读/写常见地址）

#### 读操作（CMD=0x03）

```
XOR = AA ^ 55 ^ 03 ^ AddrL ^ AddrH ^ Count
```

| 地址 | 地址(HEX) | 读长度 | 完整帧 (HEX) | XOR |
|------|----------|--------|-------------|-----|
| 00004 | `0x0004` | 1 | `AA 55 03 04 00 01` | `^^ = 0xF9` → `AA 55 03 04 00 01 F9` |
| 00008 | `0x0008` | 1 | `AA 55 03 08 00 01` | `^^ = 0xF5` → `AA 55 03 08 00 01 F5` |
| 00010 | `0x000A` | 1 | `AA 55 03 0A 00 01` | `^^ = 0xF7` → `AA 55 03 0A 00 01 F7` |
| 00100 | `0x0064` | 1 | `AA 55 03 64 00 01` | `^^ = 0x99` → `AA 55 03 64 00 01 99` |
| 00001 | `0x0001` | 3 | `AA 55 03 01 00 03` | `^^ = 0xFE` → `AA 55 03 01 00 03 FE` |
| 00018 | `0x0012` | 2 | `AA 55 03 12 00 02` | `^^ = 0xEC` → `AA 55 03 12 00 02 EC` |

#### 写单个（CMD=0x06，2 字节数据，小端）

```
XOR = AA ^ 55 ^ 06 ^ AddrL ^ AddrH ^ 02 ^ D0 ^ D1
```

**写蠕动泵转速 500 (0x01F4) → 地址 0x0008：**

| 字段 | AA | 55 | 06 | 08 | 00 | 02 | F4 | 01 |
|------|----|----|----|----|----|----|----|----|
| 值 | AA | 55 | 06 | 08 | 00 | 02 | F4 | 01 |
| 逐次 XOR | AA | FF | F9 | F1 | F1 | F3 | 07 | **06** |

→ 完整帧：`AA 55 06 08 00 02 F4 01 06`

**写针头清洗=1 → 地址 0x0004（UNS8 = 1 字节）：**

虽然 CMD=0x06 写单寄存器，但数据长度就是对应类型长度。UNS8=1字节:

```
XOR = AA ^ 55 ^ 06 ^ 04 ^ 00 ^ 01 ^ 01 = 0xFD
```
→ 完整帧：`AA 55 06 04 00 01 01 FD`

## 测试用例

### 前置条件

1. STM32 上电，调试口 UART1 能看到启动日志
2. UART2 连接上位机，串口助手设为 **HEX 模式**
3. CAN 总线连接 CANfrom站或 USB-CAN 分析仪

### TC-01：基础连通性

**目的**：验证串口帧能被接收并响应

**操作**：
```
发 (HEX): AA 55 03 08 00 01 F5
```

**预期响应**（需 CAN 从站在线）：
```
AA 55 03 08 00 02 [2字节数据] [XOR]
```

**场景 1：CAN 从站离线**

预期响应：
```
AA 55 FF 03 08 00 00 XX   // 错误码 0x03（地址无路由或 SDO 超时）
```

### TC-02：XOR 校验错误

**目的**：验证错误帧检测机制

**操作**：
```
发 (HEX): AA 55 03 08 00 01 00   // XOR 应该是 F5，故意发 00
```

**预期响应**：
```
AA 55 FF 01 00 XX   // 错误码 0x01（校验和错误）
```

### TC-03：未知命令

**目的**：验证非法命令处理

**操作**：
```
发 (HEX): AA 55 12 08 00 01 E4   // CMD=0x12 非法，XOR=AA^55^12^08^00^01=E4
```

**预期响应**：
```
AA 55 FF 02 00 XX   // 错误码 0x02（未知命令）
```

### TC-04：读不存在地址

**目的**：验证地址越界处理

**操作**：
```
发 (HEX): AA 55 03 FF FF 01 FD   // 地址 0xFFFF 不存在
```

**预期响应**：
```
AA 55 FF 03 XX   // 错误码 0x03（路由未找到）
```

### TC-05：读蠕动泵转速（CAN 从站在线）

**目的**：验证 SDO 读链路

**操作**：
```
发 (HEX): AA 55 03 08 00 01 F5
```

**预期 CAN 总线行为**：
```
主站发 SDO Upload:  601 40 04 20 00 00 00 00 00
从站应 SDO Response: 581 43 04 20 00 XX XX 00 00
```

**预期串口响应**：
```
AA 55 03 08 00 02 XX XX YY     // XX XX = 当前转速(小端), YY = XOR
```

### TC-06：写蠕动泵转速=500

**目的**：验证 SDO 写链路

**操作**：
```
发 (HEX): AA 55 06 08 00 02 F4 01 06
```

**预期 CAN 总线行为**：
```
主站发 SDO Download: 601 2B 04 20 00 F4 01 00 00
```

**预期串口响应**：
```
AA 55 06 08 00 00 F1   // 成功，空数据
```

### TC-07：写只读地址

**目的**：验证权限检查

**操作**（读孔位状态地址 0x0001，但用写命令）：
```
发 (HEX): AA 55 06 01 00 02 00 00 FA   // XOR=AA^55^06^01^00^02^00^00=FA
```

**预期响应**：
```
AA 55 FF 04 00 XX   // 错误码 0x04（访问权限错误）
```

### TC-08：写多个寄存器 0x10

**目的**：验证批量写

**操作**（写参数地址 0x120=0x0078，2 字节）：
```
发 (HEX): AA 55 10 78 00 02 00 01 94   // XOR=AA^55^10^78^00^02^00^01=94
```

**预期响应**：
```
AA 55 10 78 00 00 XX   // 成功
```

### TC-09：SDO 超时（CAN 从站离线）

**目的**：验证无从站时的超时处理

**操作**：
```
发 (HEX): AA 55 03 08 00 01 F5
```

**预期：**
1. 主站发 SDO Upload 到 CAN 总线
2. 因无从站响应，SDO 超时
3. 串口响应错误帧：
```
AA 55 FF 03 08 00 00 XX   // 0x03 = SDO 超时
```

### TC-10：批量连续读 3 个寄存器

**目的**：验证批量读

**操作**（读孔位状态 0x0001 ~ 0x0003，UNS64=8字节）：
```
发 (HEX): AA 55 03 01 00 03 FE
```

**预期响应**：
```
AA 55 03 01 00 08 [8字节数据] [XOR]
```

### TC-11：帧头失同步恢复

**目的**：验证状态机能从中间字节恢复

**操作**（先发垃圾字节再发合法帧）：
```
发 (HEX): FF EE DD AA 55 03 08 00 01 F5
```

**预期**：第一个字节 FF 导致状态机保持 S_HDR1，直到 AA 出现才重新同步。
最终仍然正确响应蠕动泵转速读请求。

## 错误排查

### 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 收到 `AA 55 FF 01` | XOR 校验失败 | 检查发送帧的 XOR 计算是否正确；确认未追加回车换行 |
| 收到 `AA 55 FF 03` | 地址无路由或 SDO 超时 | 确认 CAN 从站在线；检查路由表是否有该地址 |
| 无任何响应 | 串口未连通或状态机卡住 | 发送完整帧让状态机重新同步；检查接线和波特率 |
| 响应乱码 | 串口助手未设为 HEX 模式 | 确认发送和接收都是 HEX 模式 |
| UART2 有日志文本 | 配置错误 | 检查 `rtconfig.h` 中 `RT_CONSOLE_DEVICE_NAME` 是否为 `"uart1"` |
| 日志口有 AA55 乱码 | 接线混了 | 确认 UART1 接调试电脑，UART2 接上位机 |

### 快速验证脚本（Python）

```python
#!/usr/bin/env python3
"""CANopen STM32 串口协议快速测试"""
import serial

def xor_checksum(data: bytes) -> bytes:
    x = 0
    for b in data:
        x ^= b
    return data + bytes([x])

def send_frame(ser: serial.Serial, frame: bytes):
    """发帧并读响应"""
    full = xor_checksum(frame)
    ser.write(full)
    resp = ser.read(32)
    print(f"发: {full.hex(' ').upper()}")
    print(f"收: {resp.hex(' ').upper()}")
    return resp

def main():
    with serial.Serial("COM4", 115200, timeout=2) as ser:
        print("=== TC-01: 读蠕动泵转速 ===")
        send_frame(ser, bytes([0xAA, 0x55, 0x03, 0x08, 0x00, 0x01]))

        print("\n=== TC-06: 写转速=500 ===")
        send_frame(ser, bytes([0xAA, 0x55, 0x06, 0x08, 0x00, 0x02, 0xF4, 0x01]))

        print("\n=== TC-02: 故意错 XOR ===")
        ser.write(bytes([0xAA, 0x55, 0x03, 0x08, 0x00, 0x01, 0x00]))
        resp = ser.read(16)
        print(f"收: {resp.hex(' ').upper()}")

if __name__ == "__main__":
    main()
```

> 将 `COM4` 改为实际 UART2 的端口号。
