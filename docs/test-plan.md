# 快检设备 Modbus-CANopen 网关测试计划

## 测试环境

```
PC (串口助手) ──UART2──→ STM32 (Modbus Slave) ──CAN──→ CAN分析仪 (Node 0x02)
                              │
                          UART1 (控制台/日志)
```

| 接口 | 引脚 | 参数 |
|------|------|------|
| UART1 (控制台) | PA9 TX, PA10 RX | 115200 8N1 |
| UART2 (Modbus) | PA2 TX, PA3 RX | 115200 8N1 |
| CAN1 | PA12 TX, PA11 RX | 50 Kbps |

---

## 1. 基础功能测试（无 CAN 从机）

无需连接 CAN 分析仪，寄存器读写回退到本地内存。

### 1.1 控制台自检

| 步骤 | 命令 | 预期结果 |
|:---:|------|----------|
| 1 | `mb_test 4` | WRITE PASS, CANopen read skipped, restored |
| 2 | `mb_write 4 123` | 显示 `0004 <- 0x007B (123)` |
| 3 | `mb_read 4` | 显示 `0004: 0x007B (123)` |
| 4 | `mb_dump` | 显示全部寄存器，00004 处为 007B |

### 1.2 外部 Modbus Master 测试

串口助手连接 UART2，115200 8N1，十六进制收发：

#### 1.2.1 FC03 读保持寄存器

| 操作 | 发送 | 接收 |
|:---:|------|------|
| 读 00004 | `01 03 00 03 00 01 74 0A` | `01 03 02 00 00 B8 44` |
| 读 00001~00003 | `01 03 00 00 00 03 04 0B` | `01 03 06 00 00 00 00 00 00 ...` |
| 读 00100 | `01 03 00 63 00 01 D5 D5` | `01 03 02 xx xx CR CH` |

#### 1.2.2 FC06 写单个寄存器

| 操作 | 发送 | 接收 |
|:---:|------|------|
| 写 00004=123 | `01 06 00 03 00 7B 39 E9` | `01 06 00 03 00 7B 39 E9` |
| 写 00004=0 | `01 06 00 03 00 00 B9 E9` | `01 06 00 03 00 00 B9 E9` |

#### 1.2.3 FC16 写多个寄存器

| 操作 | 发送 | 接收 |
|:---:|------|------|
| 写 00004=123 | `01 10 00 03 00 01 02 00 7B E6 40` | `01 10 00 03 00 01 51 C8` |

#### 1.2.4 写后读验证

| 步骤 | 操作 | 预期 |
|:---:|------|------|
| 1 | `01 06 00 03 00 7B 39 E9` | 写入 123 |
| 2 | `01 03 00 03 00 01 74 0A` | 读到 `00 7B` = 123 |
| 3 | 控制台 `mb_read 4` | 显示 123 |

## 2. CANopen 链路测试（连接 CAN 分析仪）

### 2.1 硬件连接

```
STM32 CAN1 (PA12/PA11) ←→ CAN 分析仪 (CAN_H/CAN_L)
```

CAN 分析仪配置：
- 波特率: 50 Kbps
- 工作模式: CANopen Slave
- 节点 ID: 0x02

### 2.2 启动确认

上电后 UART1 控制台日志：
```
[I/canopen] SDO client patched: node=0x02, TX=0x0602, RX=0x0582
[I/canopen] CANopen master started (Node ID=0x01, Slave=0x02)
```

CAN 分析仪应收到 NMT 启动帧：`0x000 01 02`

### 2.3 SDO 读写测试

#### 2.3.1 控制台测试

| 命令 | 预期 |
|------|------|
| `mb_sim 4 1` | CANopen OK - 从分析仪读到寄存器4 |
| `mb_write 4 123` | 本地写入 + SDO 推送到分析仪 |
| `mb_sim 4 1` | CANopen OK - 验证写入的值 |

#### 2.3.2 Modbus 透传测试

| 步骤 | 串口助手发送 | CAN 分析仪应收到 |
|:---:|------|:---:|
| 读 00004 | `01 03 00 03 00 01 74 0A` | SDO Read: 0x2001 |
| 写 00004=123 | `01 06 00 03 00 7B 39 E9` | SDO Write: 0x2001 = 0x7B |
| 读 00100(温度) | `01 03 00 63 00 01 D5 D5` | SDO Read: 0x2100 |
| 写 00120(控制) | `01 06 00 77 00 01 CRCH` | SDO Write: 0x2200 = 0x01 |
| 读 00150(速度) | `01 03 00 95 00 01 CRCH` | SDO Read: 0x2210 |

## 3. 完整协议验证

### 3.1 寄存器映射表验证

| 区域 | Modbus 地址 | 测试方法 | 预期 |
|:---:|:---:|------|------|
| 孔位状态 | 00001~00003 | 读 → 64bit | 分析仪返回 8 字节 |
| 清洗针头 | 00004 | 写 1 → 读 → 验证 = 1 | SDO 0x2001 |
| 取液/注液 | 00005 | 写 2 → 读验证 | SDO 0x2002 |
| 转盘使能 | 00011 | 写 0x08 → 读验证 | SDO 0x2007 |
| 光强读数 | 00016~00017 | 读 → 32bit float | SDO 0x200A |
| 转盘温度 | 00100 | 写 2500(25.00℃) → 读验证 | SDO 0x2100 |
| 参数控制字 | 00120 | 写 1 → 读验证 | SDO 0x2200 |
| 样品盘速度 | 00150 | 写 500 → 读验证 | SDO 0x2210 |
| 洗针深度 | 00164 | 写 50(5mm) → 读验证 | SDO 0x221E |
| 洗针位角度 | 00172 | 写 1000 → 读验证 | SDO 0x2226 |
| 柱塞泵取液 | 00197 | 写 100μL → 读验证 | SDO 0x223F |

### 3.2 边界测试

| 测试 | 操作 | 预期 |
|------|------|------|
| 读超出范围地址 | `01 03 00 C8 00 01 ...` (addr 201) | 异常响应 `01 83 02 CR CH` |
| 写只读寄存器 | `01 06 00 00 00 01 ...` (addr 1 是只读) | 异常响应 `01 86 02 CR CH` |
| 广播地址 | `00 03 00 00 00 01 ...` | 不回复 |
| 错误 CRC | `01 03 00 03 00 01 00 00` | 无响应 |

## 4. 测试命令速查（UART1 控制台）

| 命令 | 格式 | 说明 |
|------|------|------|
| `mb_test` | `mb_test [addr]` | 写-读-验证自动测试 |
| `mb_read` | `mb_read <addr> [count]` | 读寄存器 |
| `mb_write` | `mb_write <addr> <value>` | 写寄存器 |
| `mb_sim` | `mb_sim <addr> [count]` | 模拟 Modbus Master（走 CANopen） |
| `mb_dump` | `mb_dump` | 显示所有寄存器 |

## 5. 异常排查

| 现象 | 原因 | 解决 |
|------|------|------|
| 读回 `00 00` | CANopen 无从机，回退到本地内存 | 接 CAN 分析仪 |
| `[E/router] SDO read failed: rc=255` | CANopen 节点无响应 | 确认分析仪在线、节点 ID=0x02、波特率 50K |
| `Heartbeat lost: node 0x00` | 无 CAN 设备 | 正常，可忽略 |
| Modbus 写无回显 | CRC 错误 | 重新计算 CRC16-Modbus |
| Modbus 无反应 | 接线错误 | 检查 UART2 PA2/PA3 交叉连接 |
