## 二、转盘轴 (Node3) 完整位置分析

### 10 个唯一位置值

| 位置值 | 含义 | 出现频率 |
|--------|------|---------|
| **-19** (0xFFFFED) | **空闲/原点位置** | 最高频, 约 50% 时间 |
| **13980** (0x369C) | 测量位 0 (基准位) | 高频 |
| **13847** (0x3617) | 测量位 1 | 中频 |
| **13447** (0x3487) | 测量位 2 | 低频 |
| **12914** (0x3272) | 测量位 3 | 中频 |
| **10647** (0x2997) | 测量位 4 | 低频 |
| **5180** (0x143C) | 测量位 5 | 中频 |
| **3847** (0x0F07) | 测量位 6 (最远端) | 低频 |
| **-3** (0xFFFFFD) | 预归零位置 | 极低频 |
| **0** (0x000000) | 绝对零点 | 极低频 |

### 完整时序序列

```
t=0-53s:   空闲 (pos=-19), 0x206=0x00
t=53s:     0x206 切换到 0x18 (开始测量)
t=53-74s:  转到 13980 (测量位0), 停留 ~21s
t=74-78s:  空闲 → 转到 3847 (测量位6)
t=78-107s: 测量位6, 停留 ~29s
t=107-110s: 空闲 → 转到 3847 (测量位6, 重复)
t=110-130s: 测量位6
t=130-132s: 空闲 → 转到 13980 (测量位0)
t=132-155s: 测量位0
t=155-158s: 空闲 → 转到 13980
t=158-162s: 测量位0
t=162-165s: 空闲 → 转到 10647 (测量位4)
... (重复模式)
```

**模式总结**：空闲 → 测量位 → 空闲 → 下一个测量位 → ...  
每个测量位停留 ~3-25 秒, 空闲停留 ~2-30 秒

## 三、关键控制信号

### RPDO1 Node6 (0x206) — 测量模式

```
0x00000000 → 非测量模式 (空闲/转盘运动)
0x00000018 → 测量模式 (传感器激活)
0xFFFFFC0D → 短暂中间值 (模式切换瞬间)

时间线:
  t=0-6s:   0x00000000 (空闲)
  t=6-510s: 0x00000018 (测量中, 持续 504 秒!)
  t=510s:   0x00000000 (结束)
```

### RPDO2 Node1 (0x301) — 电机A

```
位置固定: 500 (0x01F4)
控制字: 0x0001F400
在整个采样周期内不变
```

### RPDO2 Node2 (0x302) — 电机B

```
位置固定: 85333 (0x014D55)
控制字: 0x00014D55
在整个采样周期内不变
```

### RPDO2 Node4 (0x304) — 升降轴

```
位置固定: -3 (0xFFFFFD)
控制字: t=0-360s: 0x019000 → t=360-512s: 0x032000
在 ~360秒 处控制字发生变化 (可能是切换到不同泵速)
```

## 四、Node6 编码器反馈 (0x186)

### 位置范围与含义

```
0x5A00 ~ 0x5AFF (23040-23295): 测量位 "高位" (转盘在测量位置)
0x5400 ~ 0x59FF (21504-23039): 不同测量位
0x4900 ~ 0x4FFF (18688-20479): 过渡区
0x0100 ~ 0x0500 (256-1280): 空闲/原点区域
```

### 变化波形

```
t=0-6s:    0x0117 (279) — 在原点
t=6-36s:   0x5Axx (23k) — 转盘转到测量位
t=36-52s:  0x0117 (279) — 回到原点
t=52-117s: 0x5Axx (23k) — 新一轮测量
...
```

## 五、与 Modbus 数据的对照

CAN数据 (8.5分钟) 与 Modbus 数据 (14:48-14:57, ~11分钟) 来自不同的采集, 但业务流程一致:

| 阶段 | Modbus 侧 (上位机) | CAN 侧 (MCU→驱动) |
|------|-------------------|-------------------|
| 初始化 | 写 0x000B=0x8000 | NMT Start + SDO |
| 转盘旋转 | 高频读 0x0000(3) | RPDO2 N3 位置参数变化 |
| 孔位切换 | 写 0x000B=0xC000 | Node3 位置切换到新值 |
| 测量开始 | 写 0x0004=0x8000 | RPDO1 N6 = 0x18 |
| 传感器读数 | 读 0x0063/0x0064 | TPDO1 N8 双通道反馈 |
| 孔位编码 | 读 0x0000-0x0002 | TPDO1 N6 位置反馈 |

## 六、MCU 代码 — 完整采样周期骨架

基于 CAN 数据的分析, MCU 需要实现的核心逻辑:

```c
// 转盘测量位定义 (从 CAN 数据提取)
static const int32_t slot_positions[] = {
    13980,  // 测量位 0 (基准)
    13847,  // 测量位 1
    13447,  // 测量位 2
    12914,  // 测量位 3
    10647,  // 测量位 4
     5180,  // 测量位 5
     3847,  // 测量位 6
};
#define SLOT_COUNT  7
#define IDLE_POS   (-19)

// 采样周期状态机
typedef enum {
    SAMPLE_IDLE,
    SAMPLE_MOVE_TO_SLOT,
    SAMPLE_WAIT_STABLE,
    SAMPLE_MEASURE,
    SAMPLE_MOVE_TO_IDLE,
    SAMPLE_NEXT_SLOT,
    SAMPLE_DONE,
} sample_state_t;

// 一个孔的测量流程:
// 1. set Node3 pos = slot_positions[i]
// 2. set RPDO1 N6 = 0x18  (测量模式)
// 3. wait for Node6 TPDO1 to stabilize
// 4. read sensors (Node8 TPDO1)
// 5. set Node3 pos = -19  (回空闲)
// 6. report results to Modbus registers
```
