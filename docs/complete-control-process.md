# 快检设备完整控制流程 — 三数据源综合分析

> **数据源**:
> - `上位机发送的modbus数据.txt` — 上位机→MCU 的 Modbus 请求帧 (2,238 条)
> - `上位机接收的modbus数据.txt` — MCU→上位机的 Modbus 应答帧 (2,344 条)
> - `一次采样的数据.csv` — CAN 总线监控 (520,874 帧, 512 秒)
>
> **结论**: 上位机通过 Modbus RTU 下发指令, MCU (STM32) 解析后通过 CANopen 控制 4 轴伺服 + 传感器采集, 完成全自动农药残留检测。

## 三、Phase 0 — 初始化握手 (80ms)

### Modbus 侧

```
上位机在 80ms 内连续发出 6 帧 (不等应答):

帧1: 03 读 0x000B(1)    → 查询电机控制寄存器
帧2: 06 写 0x000B=0x8000 → 设电机为空闲状态
帧3: 03 读 0x000F(1)    → 查询配置寄存器
帧4: 06 写 0x000F=0x8000 → 设配置标志
帧5: 03 读 0x0078(1)    → 查询参数控制字
帧6: 06 写 0x0078=0x0006 → 设控制字=搅拌混合(初始态)
```

### CAN 侧 (对应操作)

```
MCU 收到 Phase 0 握手后:
  1. NMT 启动 Node1, Node4, Node7
  2. SDO 写 Node1 0x6083/00 = 300 (加速度)
  3. SDO 写 Node2 0x6083/00 = 50
  4. SDO 写 Node3 0x6083/00 = 500
  5. SDO 写 Node3 0x6084/00 = 500
  6. RPDO2 全部置零 (所有电机静止)
```

## 四、Phase 1 — 稳态轮询 (14:48:05 ~ 14:48:26, ~21秒)

### Modbus 侧

```
轮询周期: 每 5 秒 1 轮

每轮帧序:
  上位机 → 03 读 0x0012(2)   (设备状态)
  上位机 → 03 读 0x0063(1)   (温度传感器1)
  MCU → 03 04 10 00 00 00    (状态 = 0x1000 0x0000)
  MCU → 03 02 0D 8C          (温度1 = 3468 → 34.68°C)
  上位机 → 03 读 0x0064(1)   (温度传感器2)
  MCU → 03 02 06 D6          (温度2 = 1750)

传感器趋势 (4轮, ~20秒):
  温度1: 0D8C → 0DCC → 0E19 → 0E5B  (递增)
  温度2: 06D6 → 06BA → 0699 → 067B  (递减)
```

### CAN 侧 (对应)

```
RPDO2 保持空闲:
  Node1: pos=500 (固定)
  Node2: pos=85333 (固定)
  Node3: pos=-19 (空闲原点)
  Node4: pos=-3 (就绪位置)

TPDO 反馈正常运行:
  Node6: 位置在 0x0117 附近 (原点)
  Node8: ch1≈-99, ch2 空闲值
```

## 五、Phase 2 — 孔位扫描 + 转盘旋转 (14:48:26 ~ 14:48:57, ~31秒)

### 这是整个流程中最关键的阶段。上位机通过 Modbus 高频轮询追踪转盘位置。

### Modbus 侧

```
(1) 启动孔位扫描
  上位机 → 03 读 0x0000(3)
  MCU → FC 00 01 00 00 70   (当前孔位编码)
  上位机 → 10 写 0x0000(3) = FC 00 01 00 00 73  (写回编码)

(2) 高频轮询开始 — 每 30ms 一次!
  上位机 → 03 读 0x0000(3)
  上位机 → 03 读 0x0000(3)  ← 不等上一个应答!
  上位机 → 03 读 0x0000(3)
  ...

(3) MCU 返回的孔位编码逐步变化:
  FC 00 01 00 00 70 → FC 02 01 00 80 73 → FC 03 01 00 C0 73
  → ... → FF 03 31 FF FF F0 (共 18 个微步阶段)
```

### CAN 侧 (对应 — 这是核心!)

```
上位机写 0x0000(3) → MCU 转换 → CANopen RPDO2 Node3 位置命令

Node3 (转盘轴) 在 10 个预定义位置之间切换:

  pos = -19    ← 空闲/原点 (旋转之间的状态)
  pos = 13980  ← 测量位 0 (基准)
  pos = 13847  ← 测量位 1
  pos = 13447  ← 测量位 2
  pos = 12914  ← 测量位 3
  pos = 10647  ← 测量位 4
  pos = 5180   ← 测量位 5
  pos = 3847   ← 测量位 6

控制流:
  1. MCU 将 Modbus 孔位选择 解码为 CAN 位置值
  2. MCU 将位置值写入 mZ_position → RPDO2 Node3 发送
  3. 伺服电机执行位置移动
  4. 编码器反馈 (TPDO1 Node6) → MCU 采集
  5. MCU 将编码器位置 编码为 6 字节孔位编码
  6. MCU 更新 Modbus 寄存器 0x0000~0x0002
  7. 上位机下一个 30ms 轮询读到新值
```

### 孔位编码格式

```
6 字节 = 3 个 16bit 寄存器 (0x0000~0x0002)

Byte[0:1]: 孔位索引 (0xFC00 ~ 0xFF31)
Byte[2]:   0x00 (固定)
Byte[3]:   微步掩码 (0x00→0x80→0xC0→...→0xFF, 8 级)
Byte[4:5]: 校验和 (随位置变化)
```

## 六、Phase 3 — 针泵操作 (14:48:59 ~ 14:49:22, ~23秒)

### Modbus 侧

```
(1) 针泵控制命令
  上位机 → 06 写 0x0078 = 0x0004   (控制字: 洗针)
  上位机 → 06 写 0x0004 = 0x8000   (触发执行!)

(2) 等待完成 — 每 0.5~1 秒轮询一次 0x0004
  每次读回: 0x0004 = 0x8000 (执行中...)
  持续 23 秒, 共约 35 次轮询!

(3) 同时每 ~1 秒穿插全状态读取:
  读 0x0012(2) + 0x0063(1) + 0x0064(1)
  
传感器在此期间的变化:
  温度1: 0x0E67 → 0x0E74 (微升)
  温度2: 0x05C9 → 0x0577 (微降)
```

### CAN 侧 (对应)

```
针泵操作期间, CAN 总线保持当前状态:
  RPDO2 Node1-4 继续发送 (Node3 在测量位)
  RPDO1 Node6 = 0x18 (测量模式)
  TPDO 反馈正常更新

MCU 需要同时:
  1. 维护 CANopen 总线通信
  2. 响应上位机 Modbus 轮询
  3. 控制针泵动作 (可能通过 GPIO 或另一个 CAN 节点)
```

## 七、Phase 4 — 电机运动 + 测量循环 (14:49:22 ~ 14:50:18)

### 这是完整的单个测量孔位周期。

### Modbus 侧

```
(1) 电机参数设置 (14:49:22.701 ~ 14:49:22.951, ~250ms)
  上位机 → 06 写 0x0008 = 0x0BB8  (步数 = 3000)
  上位机 → 06 写 0x0009 = 0x002F  (模式 = 47)
  上位机 → 10 写 0x000C(3) = 0x0400, 0x0000, 0x0000
  上位机 → 06 写 0x000B = 0x9000  (启动电机!)

(2) 等待电机完成 (14:49:23 ~ 14:49:24, ~1.1秒)
  上位机 → 03 读 0x000B
  MCU → 0x000B = 0x9000 (运动中)
  上位机 → 03 读 0x000B
  MCU → 0x000B = 0x8000 (完成!)

(3) 启动泵 (14:49:24)
  上位机 → 06 写 0x000A = 0x0400  (泵配置)
  上位机 → 10 写 0x0006(2) = 0x2710, 0x0000
  上位机 → 06 写 0x0005 = 0x2000  (启动泵)

(4) 测量数据采集 (14:49:24 ~ 14:50:18, ~54秒)
  每 ~1 秒读: 0x0005 + 0x0012(2) + 0x0063(1) + 0x0064(1)
  
  传感器1 (温度) 波形:
    0x0E6A ──下降──→ 0x0E58 ──急速上升──→ 0x0E9D
    ──平台 5 秒──→ 0x0E9D ──下降──→ 0x0E58
         ↑ 这是测量读数窗口!
```

### CAN 侧 (对应)

```
电机启动 (0x000B=0x9000):
  MCU → Node3 RPDO2 位置 = 新测量位值
  MCU → RPDO1 Node6 = 0x18 (测量模式)

泵启动 (0x0005=0x2000):
  MCU → Node1/Node2 RPDO2 控制字变化
  (或通过其他 CAN 节点控制蠕动泵)

测量数据采集:
  TPDO1 Node6 (编码器) → 位置反馈 → Modbus 孔位编码
  TPDO1 Node8 (传感器) → 温度数据 → Modbus 0x0063/0x0064
```

### 传感器波形的物理含义

```
                              ┌──────────┐
                              │ 平台稳定  │ ← 测量读数窗口
   上升段 (样品进入光路) →   /            \    ← 下降段 (样品移出)
                          /                \
  ─────────────────────/                    \──────────
  空闲 (无样品)                                   空闲 (无样品)
```

## 八、Phase 5 — 多孔位循环 (14:50:18 ~ 14:56:38, ~6分20秒)

### 这是 Phase 4 的重复, 每个孔位经历相同的流程。

### Modbus 侧 (孔位切换)

```
孔位切换控制序列 (14:50:18):
  上位机 → 06 写 0x0004 = 0x1000  (就绪模式)
  上位机 → 06 写 0x0009 = 0x0025  (模式切换)
  上位机 → 06 写 0x000B = 0xC000  (回零/切换孔位!)
  等待 ~6 秒...
  MCU → 0x000B = 0xC000 → 上位机写 0x8000 (停止)
```

### CAN 侧 (对应)

```
Node3 位置序列 (8.5分钟内的完整循环):

t=53s:   13980 (孔0基准)  停留 21s
t=78s:   3847  (孔6远端)  停留 29s
t=110s:  3847  (孔6重测)  停留 20s
t=132s:  13980 (孔0)      停留 23s
t=158s:  13980 (孔0重测)  停留 4s
t=165s:  10647 (孔4)      停留 5s
t=174s:  5180  (孔5)      停留 5s
t=180s:  13980 (孔0)      停留 11s
t=194s:  10647 (孔4)      停留 6s
t=203s:  5180  (孔5)      停留 5s
t=210s:  13980 (孔0)      停留 10s
...(继续循环, 共变换 83 次位置)

t=510s:  0x206 = 0x00 (测量结束)
```

### 每个孔位的完整子流程

```
┌─────────────────────────────────────────────────┐
│ ① 上位机写 Modbus → MCU 转 CAN 位置命令        │
│    0x000B=0xC000 (切孔) → Node3 归零 (-19)     │
│                              ↓                  │
│ ② 上位机写运动参数                              │
│    0x0008=步数, 0x0009=模式                     │
│                              ↓                  │
│ ③ 上位机写 0x000B=0x9000 (启动)                │
│    → Node3 位置切换到新孔位                     │
│                              ↓                  │
│ ④ 上位机轮询 0x000B 等待完成 (~1秒)            │
│    → MCU 监控 Node3 TPDO1 状态                 │
│                              ↓                  │
│ ⑤ 上位机写 0x0005=0x2000 (启动泵)              │
│    → 传感器开始采集                             │
│                              ↓                  │
│ ⑥ 上位机每 ~1秒 读取传感器 (0x0063/0x0064)     │
│    → MCU 采集 Node8 TPDO1 更新 Modbus          │
│                              ↓                  │
│ ⑦ 传感器稳定后 上位机记录读数 (~5秒平台)       │
│                              ↓                  │
│ ⑧ 上位机写 0x000B=0xC000 → 回下一个孔         │
└─────────────────────────────────────────────────┘
```

## 十一、MCU 实现检查清单

```
□ Modbus RTU Slave (地址 0x01, 115200bps)
  □ 功能码 03 (读保持寄存器)
  □ 功能码 06 (写单寄存器)
  □ 功能码 10 (写多寄存器)
  □ 30ms 内必须应答 (上级会不等应答连发)

□ CANopen Master (Node ID 0x00)
  □ NMT Master — 启动/停止从站
  □ SDO Client — 配置从站参数 (0x6083/0x6084)
  □ RPDO2 — 4 轴位置命令 (每 ~300µs 发一帧)
  □ TPDO1 接收 — 电机状态 + 编码器反馈
  □ Heartbeat 监控 — 7 个从站

□ 核心状态机
  □ 孔位编码 ↔ CAN 位置转换
  □ 传感器数据 → Modbus 寄存器更新 (1s 周期)
  □ 动作寄存器 0x0004 处理 (触发→等待→完成)
  □ 电机控制 0x000B 处理 (停止/正转/回零)
  □ 超时保护 (动作超时自动复位)

□ 上电校验 (pwrchk)
  □ NMT 启动 Node 1,4,7
  □ SDO 批量配置加减速度
  □ RPDO2 闲置 → 运动 → 参数恢复
```
