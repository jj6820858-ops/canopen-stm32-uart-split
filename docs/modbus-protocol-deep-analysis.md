## 二、核心寄存器逐位详解

### 2.1 寄存器 0x0004 — 动作命令（最复杂）

```
+──── 0x0004 位图 ─────────────────────────────────────+
│                                                       │
│  实测值:                                              │
│  0x0000 = 空闲/动作完成                                │
│  0x1000 = 就绪/到位  (bit 12)                         │
│  0x2000 = 运动中/执行中 (bit 13)                       │
│  0x8000 = 触发执行 (bit 15)                           │
│                                                       │
│  Excel 定义值 (命令类型):                              │
│  0 = 停止                                             │
│  1 = 取液                                             │
│  2 = 加液                                             │
│  3 = 加液并混合                                       │
│  4 = 清洗比色皿                                       │
│  5 = 蠕动泵取液                                       │
│  6 = 蠕动泵加液                                       │
│                                                       │
│  ⚠️ Excel 定义的是"值域"（命令类型），                  │
│  实际还叠加了 bit 标志位（0x1000/0x2000/0x8000）。     │
│  两者是 OR 关系：命令类型 | 状态标志。                 │
+──────────────────────────────────────────────────────+
```

**上位机操作流程**：
```
Step 1: 写 0x0004 = 0x0010 (命令=16? 待确认映射)
Step 2: 写 0x0004 = 0x1000 (就绪模式)
        读 0x0004 → 0x1000 (MCU 确认就绪)
Step 3: (执行其他设置)
Step 4: 写 0x0004 = 0x8000 (触发执行)
        MCU 自动将 bit 置为 0x2000 (运动中)
        轮询直到变为 0x0000 (完成)
```

### 2.2 寄存器 0x000B — 电机控制

```
+──── 0x000B 值域 ─────────────────────────────────────+
│                                                       │
│  0x8000 = 空闲/停止 (电机未使能)                       │
│  0x9000 = 电机 A 正向运动                             │
│  0xA000 = 电机 B 正向运动（后续周期出现）              │
│  0xC000 = 回零 / 孔位切换                             │
│                                                       │
│  上位机流程:                                          │
│  1. 写运动参数                                        │
│  2. 写 0x000B = 0x9000 (启动)                        │
│  3. 轮询 0x000B 直到 ≠ 0x9000                        │
│  4. 电机完成后 MCU 写回 0x8000                        │
│                                                       │
│  注意: 0x000B 返回有时滞—MCU 可能需要几 ms             │
│  才有响应，粘包时新值出现在下一帧。                    │
+──────────────────────────────────────────────────────+
```

### 2.3 寄存器 0x0000~0x0002 — 转盘位置编码

```
6 字节编码结构:

Byte[0]:  孔位索引高字节 ─┐
Byte[1]:  孔位索引低字节 ─┴─ 16bit 孔位号 (0xFC00 → 0xFF31)
Byte[2]:  0x00 (固定)
Byte[3]:  微步掩码 (逐位 set: 0x00→0x80→0xC0→0xE0→0xF0→0xF8→0xFC→0xFE→0xFF)
Byte[4]:  校验/状态高字节 ─┐
Byte[5]:  校验/状态低字节 ─┴─ 随位置变化

完整旋转序列 (18个微步阶段):
  FC 00 01 00 00 70   初始位置
  FC 02 01 00 80 73   +微步[0x80]
  FC 03 01 00 C0 73   +微步[0xC0]
  FC 03 01 00 E0 73   +微步[0xE0]
  FC 03 01 00 F0 73   +微步[0xF0]
  FC 03 21 00 F8 73   +微步[0xF8], 索引跳变!
  FC 03 31 00 FC 73   +微步[0xFC]
  FC 03 31 00 FE 73   +微步[0xFE]
  FC 03 31 00 FF 73   +微步[0xFF]
  FC 03 31 00 FF F3   校验跳变
  FE 03 31 80 FF F3   索引高位[FC→FE], 微步复位[0x80]
  FF 03 31 C0 FF F3   索引高位[FE→FF]
  FF 03 31 E0 FF F3
  FF 03 31 F0 FF F3
  FF 03 31 F8 FF F3
  FF 03 31 FC FF F3
  FF 03 31 FE FF F3
  FF 03 31 FF FF F0   终点位置
```

### 2.4 寄存器 0x0063/0x0064/0x0065 — 传感器数据

```
0x0063 (PLC 00100 - 加热温度):
  范围: 0x0D8C ~ 0x0EA2
  换算: 值 ÷ 100 = °C (3468 → 34.68°C)

0x0064 (PLC 00101 - 制冷温度):  
  在这个测试场景中似乎未使用传感器2的变化模式
  值始终也在 0x04A8 ~ 0x06D6 范围内

0x0065 (PLC 00102 - 重量):
  范围: 0x02FC ~ 0x06D6
  趋势: 整个实验过程中单调递减

⚠️ 这三个寄存器的确切物理含义需要对照 Excel + 实验场景确认。
   Excel 定义:
   - 00100 = 转盘加热温度
   - 00101 = 酶试剂制冷温度  
   - 00102 = 清水瓶重量
```

## 六、MCU 代码实现关键约束

### 6.1 Modbus 帧处理

```
1. 地址: 0x01
2. 功能码: 必须支持 0x03, 0x06, 0x10
3. 波特率: 标准 Modbus (推测 115200)
4. 校验: CRC-16, 低字节在前
5. 应答时限: 必须在 30ms 内开始应答
6. 异常码: 必须支持 01(非法功能), 02(非法地址), 03(非法数据)
```

### 6.2 寄存器行为

```
1. 读寄存器: 立即返回当前值
2. 写寄存器: 写入后立即回显 (echo)
3. 动作寄存器(0x0004): 
   - 写入 0x8000 后, MCU 应保持该值直到动作完成
   - 动作完成后由 MCU 自动清零(写 0x0000)
4. 电机控制(0x000B):
   - 写入 0x9000/0xA000/0xC000 后保持该值
   - 运动完成后由 MCU 自动写回 0x8000
5. 孔位编码(0x0000~0x0002):
   - MCU 需要实时更新 byte[3] (微步) 和 byte[4:5] (校验)
   - 更新速率: 至少能跟上 30ms 的轮询周期
```

### 6.3 响应延迟要求

```
上位机最激进场景: 转盘旋转时每 30ms 发一次读请求
MCU 必须在 ~25ms 内准备好新数据并应答
否则上位机会不等应答就发下一帧（堆积在串口缓冲区）

⚠️ 这意味着 MCU 不能有超过 25ms 的阻塞操作
在旋转期间。传感器读取和编码更新必须是中断驱动。
```

### 6.4 粘包处理

```
上位机经常不等上一帧应答就发下一帧:
  - 初始化时: 6 帧连续发送
  - 转盘旋转时: 连续高频发送
  - 测量时: 3~4 帧粘在一起

MCU 必须:
  1. 正确地逐个解析并应答每一帧
  2. 不要在帧之间引入过长的处理延迟
  3. CRC 校验通过后才处理
```

### 6.5 寄存器默认值

```
上电初始状态:
  0x0000~0x0002 = 0x0000 (孔位未知, 需回零)
  0x0004 = 0x0000 (空闲)
  0x0005 = 0x0000 (停止)
  0x000B = 0x8000 (电机空闲)
  0x0011~0x0012 = 0x1000, 0x0000 (设备就绪)
  0x0078 = 0x0000 (无控制命令)
```
