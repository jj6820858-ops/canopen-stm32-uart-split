======================================================================
  寄存器功能总结
======================================================================

  00002~00004 = 孔位状态(3reg) [只读]
  00005       = 针头控制字 [位控制]
    0x1000 = 取液/注液启动
    0x2000 = 清洗
    0x8000 = 复位/归零
  00006       = 柱塞泵液量(half) [位控制]
    0x0800, 0x1000, 0x2000, 0x4000 = 不同液量档位
  00007~00008 = 柱塞泵液量+蠕动泵转速(2reg)
    0x2710=10000(最大液量) 0x09C4=2500(标准) 0x0064=100(小)
  00009       = 蠕动泵转速/圈数
  00010       = 操作位号 [位图] - 指定试剂/样品/比色皿位
    0x0004=位2, 0x0007=位0-2, 0x0010=位4, 0x001F=位0-4
    0x0025=位0+2+5, 0x002F=位0-5
  00011       = 转盘功能使能 [高位比特]
    0x0100=功能1, 0x0200=功能2, 0x0400=功能3(常用)
    0x0800=功能4, 0x4000=功能7, 0x8000=功能8
  00012       = 触发器 [高位比特触发动作]
    0x8000=复位/初始化, 0x9000=启动执行(最常用)
    0xA000=下一步, 0xC000=结束/切换
  00013~00015 = 转盘位号(3reg) [48bit位图]
    试剂1-5: bit0-4, 样品1-18: bit5-22, 比色皿1-18: bit23-40
  00016       = 光强读数控制
  00017~00018 = 光强读数(2reg)
  00019~00020 = 仪器状态(2reg) [0x1400=正常, 0x1C00=工作中]
  00101       = 加热温度 (值÷100=°C, 0x0EA7=37.51°C)
  00102       = 制冷温度 (值÷100=°C, 0x06D6→0x02FC, 17.5→7.6°C)
  00121       = 称重控制 [0x04=标定, 0x06=完成]
  00192       = 加热目标温度 (0x01F4=500=5.00°C)


  ╔════════════════════════════════════════════════════════╗
  ║  关键发现:                                           ║
  ║  1. 所有动作触发通过写 00012 高位 (0x8000~0xC000)    ║
  ║  2. 00011 设置功能，00012 触发执行                    ║
  ║  3. 上位机采用"写参数-写触发-轮询状态"模式          ║
  ║  4. 不通过 00120(参数控制字)启动任何动作             ║
  ║  5. 加热/制冷温度始终在后台被连续读取                ║
