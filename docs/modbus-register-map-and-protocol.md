## 二、实际通信中验证的关键寄存器行为

### 2.1 寄存器 0x0000~0x0002：孔位编码（转盘位置）

**编码格式**（6 字节 = 3×16bit）：
```
Byte[0:1] = 孔位索引 (16bit, 递增: 0xFC00 → 0xFF31)
Byte[2]   = 固定标志 0x00
Byte[3]   = 微步编码 (逐级置位: 0x00→0x80→0xC0→0xE0→0xF0→0xF8→0xFC→0xFE→0xFF)
Byte[4:5] = CRC/效验字 (随位置变化)
```

**实测旋转序列**：
```
FC 00 01 00 00 70  // 初始位置
FC 02 01 00 80 73  // 开始旋转
FC 03 01 00 C0 73  // 孔位索引+1
FC 03 01 00 E0 73
FC 03 01 00 F0 73
FC 03 21 00 F8 73  // 孔位索引 0x21 跳变！
FC 03 31 00 FC 73
FC 03 31 00 FE 73
FC 03 31 00 FF 73
FC 03 31 00 FF F3  // CRC 跳变
FE 03 31 80 FF F3  // 孔位索引高字节+1
FF 03 31 C0 FF F3
FF 03 31 E0 FF F3
FF 03 31 F0 FF F3
FF 03 31 F8 FF F3
FF 03 31 FC FF F3
FF 03 31 FE FF F3
FF 03 31 FF FF F0  // 最终位置
```

### 2.2 寄存器 0x0004：取液/注液/清洗（动作控制）

**Excel 定义 vs 实测**：
| Excel 值 | 含义 | 实测用法 |
|----------|------|---------|
| 0 | 停止 | ✅ 空闲时 |
| 1 | 取液 | 未直接观测 |
| 2 | 加液 | 未直接观测 |
| 4 | 清洗比色皿 | 未直接观测 |
| 0x8000 | (未定义) | **位15=执行中标志** |
| 0x1000 | (未定义) | **位12=到位/就绪** |

**实际工作流程**：
```
1. 上位机写 0x0004 = 特定动作值 (如 4=吸液)
2. 上位机读 0x0004 → MCU 返回 0x0000 (空闲)
3. 上位机写 0x0004 = 0x8000 → 触发执行
4. 上位机轮询 0x0004 → 返回 0x8000 (执行中)
5. 动作完成后 → 返回 0x0000 / 0x1000
```

### 2.3 寄存器 0x0005：柱塞泵液量/电机状态

**实测**：该寄存器被用作 **电机/泵运行标志**：
- `0x2000` = 电机/泵正在运转
- `0x0000` = 已停止

### 2.4 寄存器 0x000B：电机控制

**实测值域**：
| 值 | 含义 |
|----|------|
| 0x8000 | 空闲/停止 |
| 0x9000 | 正向运动 |
| 0xC000 | 回零/切换孔位 |

### 2.5 寄存器 0x0011~0x0012：仪器状态

**实测**：上位机读取 0x0012(2reg)，MCU 始终返回 `0x1000 0x0000`。
这对应 Excel 00018~00019（仪器各设备状态），`0x1000` = 位12置1。

**状态位定义**（Excel）：
```
位0: 清水箱(0=正常,1=异常)
位1: 废水箱
位2: 缓冲液
位3: 试剂
位4: 样品
位5: 比色皿
位6: 针头
位7: 温控
位30: 仪器针位(0=正常,1=异常)
位31: 仪器上电回原点(未回原点=1, 不能下发指令)
```

### 2.6 寄存器 0x0064（温度1）和 0x0065（重量1）

**实测趋势**：
```
时间        0x0064     0x0065
14:48:05    0x0D8C     0x06D6
14:48:10    0x0DCC     0x06BA
14:48:16    0x0E19     0x0699
14:48:21    0x0E5B     0x067B
...
14:50:16    0x0E9A     0x04DB
```

Excel 定义 00100=加热温度, 00101=制冷温度。但地址 0x0064 实际对应 PLC 00101。
- 值 × 100 → 0x0D8C = 3468 ÷ 100 = 34.68°C（合理加热温度范围）

### 2.7 寄存器 0x0078：参数控制字

**实测**：
| 时间 | 写值 | 读回 | 说明 |
|------|------|------|------|
| 14:47:53 | 0x0006 | 0x0006 | 初始化=6 |
| 14:48:59 | 0x0004 | 0x0006→0x0004 | 切换到吸液模式(4=洗针) |

**控制字枚举**（Excel 0120）：
```
0  = 参数保存
4  = 洗针
5  = 洗比色皿
6  = 搅拌混合
7  = 转盘震荡
8  = 加热开关
9  = 制冷开关
10 = 柱塞泵取液
11 = 柱塞泵排液
13 = 上位机启动(0=未启动,1=启动完成)
14 = 检测(0=检测中,1=完成)
15 = 光源校准
```

## 四、MCU 从站实现要点

### 4.1 Modbus 帧处理

```c
// Modbus 地址: 1
// 支持的 function code: 0x03, 0x06, 0x10
// 波特率: 115200 (推测, 根据轮询密度)
// 每个寄存器: 16bit, big-endian

#define MODBUS_SLAVE_ADDR    0x01
#define MODBUS_REG_COUNT     256    // 0x0000 ~ 0x00FF

// 寄存器文件
extern uint16_t modbus_regs[MODBUS_REG_COUNT];
```

### 4.2 关键寄存器地址宏

```c
// === 孔位与状态 ===
#define REG_HOLE_STATUS0      0x0000  // 孔位状态 [3reg]
#define REG_NEEDLE_STATUS     0x0003  // 针状态
#define REG_ACTION_CMD        0x0004  // 取液/注液/清洗命令
#define REG_SYRINGE_VOL0      0x0005  // 柱塞泵液量 [2reg]
#define REG_PERI_PUMP_SPEED   0x0007  // 蠕动泵转速
#define REG_PERI_PUMP_TURNS   0x0008  // 蠕动泵圈数
#define REG_ACTION_POS        0x0009  // 操作位号
#define REG_TURNTABLE_CTRL    0x000A  // 转盘功能使能
#define REG_ROTATE_POS0       0x000B  // 旋转位号 [3reg]
#define REG_COOLING_EN        0x000E  // 制冷使能
#define REG_LIGHT_INTENSITY   0x000F  // 光强读数 [2reg]
#define REG_DEVICE_STATUS0    0x0011  // 仪器状态 [2reg]

// === 实时数据 ===
#define REG_HEATING_TEMP      0x0063  // 加热温度 (×100)
#define REG_COOLING_TEMP      0x0064  // 制冷温度 (×100)
#define REG_WEIGHT_WATER      0x0065  // 清水瓶重量

// === 参数控制 ===
#define REG_PARAM_CTRL        0x0077  // 参数控制字
#define REG_WEIGH_CTRL        0x0078  // 称重控制
```

### 4.3 关键状态机

```c
// 动作命令寄存器 (0x0004) 的处理
typedef enum {
    ACTION_IDLE    = 0x0000,
    ACTION_DONE    = 0x1000,  // 到位/完成 (实际用法)
    ACTION_BUSY    = 0x8000,  // 执行中 (实际用法)
} action_state_t;

// 上位机流程:
// 1. 写 0x0004 = 具体动作值
// 2. 写 0x0004 = 0x8000 (触发)
// 3. 轮询读取 0x0004 直到 ≠ 0x8000
```

### 4.4 转盘位置编码

```c
// 寄存器 0x0000~0x0002 的编码结构
typedef struct {
    uint16_t hole_index;    // 孔位索引 (0x0000)
    uint16_t flags;         // 标志字节 (0x0001 低字节)
    uint8_t  micro_step;    // 微步编码 (0x0001 高字节)
    uint16_t checksum;      // 状态/CRC (0x0002)
} turntable_position_t;

// 微步编码: 每个 bit 代表一个微步阶段
// 0x00 → 0x80 → 0xC0 → 0xE0 → 0xF0 → 0xF8 → 0xFC → 0xFE → 0xFF
```

### 4.5 上位机轮询周期汇总

| 场景 | 寄存器 | 间隔 | 用途 |
|------|--------|------|------|
| 稳态监测 | 0x0012, 0x0064, 0x0065 | ~1s | 设备状态+传感器 |
| 转盘旋转 | 0x0000(3reg) | ~30ms | 监测旋转进度 |
| 动作等待 | 0x0004 或 0x000B | ~0.5s | 等待动作完成 |
| 传感器密集 | 0x0064, 0x0065 | ~1s | 测量期连续采集 |

## 五、与 CanOpen 的关系

本项目的 MCU 同时承担：
1. **Modbus RTU 从站**：与上位机（PC/工控屏）通信，执行仪器控制逻辑
2. **CanOpen 主站**：与伺服驱动器/电机控制器通信，发送运动指令

**数据流**：
```
上位机(PC) ──Modbus──→ MCU(STM32) ──CanOpen──→ 伺服/电机
   │                      │
   └── 试验流程指令       ├── 解析Modbus命令
                          ├── 转换为CanOpen运动指令
                          ├── 采集传感器 → 更新Modbus寄存器
                          └── 返回状态/数据
```

后续采集 CanOpen 通信数据后，可以进一步完善本协议分析。
